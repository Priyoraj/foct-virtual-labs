Your work stays with you

  1. Nothing is stored on the lab server. Programs run inside this browser.
  2. Use Save (Ctrl+S) to keep a file on this computer or your pen drive, and Open to continue later.
  3. Unsaved code is kept in this browser as a draft, so an accidental refresh does not lose it.
  4. On a shared lab PC, use Clear my lab data before you leave.

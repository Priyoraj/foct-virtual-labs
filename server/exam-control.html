What exam mode does

  • On every lab page, copy, cut and paste stop working: keyboard shortcuts, right-click menus and editor menus. Dragging text or files into a page is blocked too.
  • A red frame and a watermark with the exam title, the student, the PC’s network address and the time cover every page, including screenshots and printouts.
  • With sign-in, each student types their name and enrolment no. once. Their lab work then reaches this PC by itself: lab drafts changed during the exam, every file they save or download, and files they hand in with Submit files.
  • Download submissions first asks every PC for its latest work (a few seconds). It then saves Exam title.zip to this PC’s Downloads folder, with one folder per student named Name_Enrolment and a roster.csv.
  • Open pages switch within about 10 seconds. Exam mode stays on if the server restarts.
  • It stops casual copying. A student who knows the browser’s developer tools could still get around it, so for strict exams also turn off developer tools on the lab PCs with a browser policy (Edge and Chrome: DeveloperToolsAvailability = 2).

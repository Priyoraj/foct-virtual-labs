What exam mode does

  • Every exam page: copy, cut and paste stop working (keys, menus, editor menus), dragging text or files in is blocked, and a red frame and watermark (exam title, student, PC address, time) cover the page, screenshots and printouts.
  • The server itself serves only the labs you allow. With sign-in it serves them only to PCs that are signed in, not locked, and checking in every few seconds; a PC whose exam script is switched off gets no labs. Sign-in can need the exam code and one of the listed PCs. When the time limit runs out, the work is collected and the labs lock.
  • Safeguards in each page (above) block opening files, example programs, developer-tools keys, right-click and printing, and notice leaving the window, leaving full screen, text that appears 200+ characters at once in an editor, and a second screen (secure mode only). Each page also checks itself: developer tools open, or a protection removed, locks that PC.
  • Alerts appear in the table below, and Download submissions puts them in the zip: roster.csv, incidents.csv and each student’s _student.txt.
  • Merge and check similarity compares every student’s work with everyone else’s, lab by lab, and shows what matches side by side, ready for marking. With several lab servers it first merges their zips into one folder per student.
  • This stops casual cheating. A student who knows how to rewrite the exam script itself could still get around the checks inside the browser, but not the server’s part. To make it airtight, also turn off developer tools on the lab PCs with the Edge/Chrome policy DeveloperToolsAvailability = 2.

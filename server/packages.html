Add a package

Type its name, the one used with pip install. This PC downloads it from PyPI, with the packages it needs. Students then just import it, in the Python IDE and in Jupyter, also during an exam: pages that are already open pick it up at their next run, without a reload.

No internet on this PC? Drop .whl files here, or
On a PC with internet: the package’s page on pypi.org → Download files → the file ending in -none-any.whl. Bring the files of the packages it needs as well.

Good to know

  • Only pure-Python packages can be added. Packages with compiled code run in a browser only when Pyodide includes them, and those (numpy, pandas, scipy, scikit-learn, matplotlib, opencv …) are part of the lab already: students just import them.
  • In Jupyter, %pip install name finds the packages added here too, without internet.
  • After you remove a package, a page that has already imported it keeps it until that page is reloaded.
  • The packages are kept in the packages folder next to web: running setup again does not lose them.
